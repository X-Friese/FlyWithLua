Starting with FlyWithLua 2.8.15+ we have scalable fonts in imgui and support for loading custom fonts to use with your scripts. We have a folder in FlyWithLua called Custom_Fonts that provides bundled Google Fonts:

In this folder you will see:

Resources/plugins/FlyWithLua/Custom_Fonts/Roboto-Light.ttf
Resources/plugins/FlyWithLua/Custom_Fonts/Roboto-Regular.ttf
Resources/plugins/FlyWithLua/Custom_Fonts/Roboto-Medium.ttf
Resources/plugins/FlyWithLua/Custom_Fonts/Roboto-Italic.ttf
Resources/plugins/FlyWithLua/Custom_Fonts/RobotoMono-Regular.ttf

So in FlyWithLua.

Roboto-Light.ttf size 13 is 1

Roboto-Light.ttf size 16 is 2

Roboto-Light.ttf size 20 is 3

  
Roboto-Regular.ttf size 13 is 4

Roboto-Regular.ttf size 16 is 5

Roboto-Regular.ttf size 20 is 6


Roboto-Medium.ttf size 13 is 7

Roboto-Medium.ttf size 16 is 8

Roboto-Medium.ttf size 20 is 9


I have a imgui_fonts_demo_window.lua in Resources/plugins/FlyWithLua/Scripts (disabled) show some of the features.

I have a imgui_fonts_demo_window_macro.lua in Resources/plugins/FlyWithLua/Scripts (disabled) which start from the macro menu and will start better in VR.

I have a imgui_custom_fonts_demo_window.lua in Resources/plugins/FlyWithLua/Scripts (disabled) which shows how to use the new imgui_push_font(1, 20).


imgui_push_font(1) So this will use the Roboto-Light.ttf font with a size of 13.

imgui_push_font(4) So this will use the Roboto-Light.ttf font with a size of 13.

imgui_push_font(7) So this will use the Roboto-Light.ttf font with a size of 13.

The range for the fonts is 0 thru 3

This section of the fwl_prefs.ini is for fonts.

*********************************************************************
;ImguiFontSize1 = 13 Initial font1 size
ImguiFontSize1 = 13

;ImguiFontSize2 = 16 Initial font2 size
ImguiFontSize2 = 16

;ImguiFontSize3 = 20 Initial font3 size
ImguiFontSize3 = 20

;ProggyCleanDefault = 0 You are using ProggyForever
;ProggyCleanDefault = 1 You are using ProggyClean
ProggyCleanDefault = 0

;UseCustomFonts = 0 You are not using custom fonts
;UseCustomFonts = 1 You are using custom fonts
UseCustomFonts = 0

;mguiCustomFont1 = Roboto-Light.ttf This is one of the default fonts
;mguiCustomFont1 = Your font name.ttf that you added to the Custom_Fonts folder
; It will use numbers 1-3  1 being font1 size
ImguiCustomFont1 = Roboto-Light.ttf

;ImguiCustomFont2 = Roboto-Regular.ttf This is one of the default fonts
;ImguiCustomFont2 = Your font name.ttf that you added to the Custom_Fonts folder
; It will use numbers 4-6  4 being font1 size
ImguiCustomFont2 = Roboto-Regular.ttf

;ImguiCustomFont3 = Roboto-Medium.ttf This is one of the default fonts
;ImguiCustomFont3 = Your font name.ttf that you added to the Custom_Fonts folder
; It will use numbers 7-9  7 being font1 size
ImguiCustomFont3 = Roboto-Medium.ttf

**************************************************************
